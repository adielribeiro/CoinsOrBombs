Coins or Bombs

Um jogo isométrico de mineração e risco. Cada rocha pode esconder uma moeda, uma relíquia, uma bomba — ou a saída da caverna. Você tem vida suficiente para errar? Miner e descubra.

O jogo

Layout pensado para celular em paisagem, mas roda bem em desktop. Sem instalação: abra a página e jogue.

Como jogar

Tudo acontece com o mouse ou o toque. Não existe pressionar uma tecla.

Quebre a borda da área aberta Só rochas que tocam um tile já aberto podem ser quebradas. O contorno fica verde quando a rocha está ao seu alcance e vermelho quando não está.
Ache a saída escondida Uma das rochas esconde a saída da cave. Só quebrando você descobre qual é — e pode escolher continuar explorando em vez de seguir em frente.
Aprenda a ler o risco O contador 💣 mostra quantas bombas ainda restam na cave. A vida não regenera sozinha: cada bomba custa 1 ponto e zerar a vida encerra a run.
Escolha uma melhoria por cave Entre caves você recebe 3 opções de melhoria (picareta, vitalidade, moedas,utility e revelação de bombas) e pode gastar moedas para trocar as opções.
Morrer não é o fim. Você volta ao início do bioma atual, mas mantém moedas, objetivos e relíquias. Só as melhorias da run são perdidas.

O que já existe

Estado atual do protótipo, sem contar o roadmap.

🗺️

Mapa procedural por cave

Cada cave é gerada com tamanho, densidade de bombas, decoração e posição de saída próprios. A resistência das rochas sobe com a profundidade.

💣

Risco real

As bombas são plantadas nas rochas e você não tem como prever. O instinto de garimpo revela uma bomba aleatória por quebra, e a poção dedal-duro faz o mesmo na hora.

🎒

Utilitários

Poção de vida, poção dedo-duro e poção caminho seguro: compradas na loja do lobby ou encontradas em drops durante a quebra.

📈

Progressão de run

Seis trilhas de melhoria sorteadas a cada cave, com reroll pago em moedas.

🔮

Relíquias e objetivos

Uma relíquia por bioma e quatro objetivos persistentes para acompanhar.

📱

Celular em paisagem

HUD responsivo medido em tempo real, layout que se adapta e instalação como app (PWA).

Biomas

Cada bioma tem 20 caves, com paleta, cenário, densidade de moedas e de bombas próprios.

Tecnologias

React para a interface, Phaser para o mundo isométrico, Vite para o build.

⚛️

React 18

HUD, lobby, loja de utilitários, seleção de bioma e modais.

🎮

Phaser 3

Render isométrico, input, tweens e câmera.

📦

Vite 7

Dev server instantâneo e build com code-splitting entre Phaser e React.

Rodando localmente

git clone https://github.com/adielribeiro/CoinsOrBombs.git
cd CoinsOrBombs
npm install
npm run dev      # http://localhost:5173
npm run build    # gera dist/
npm run preview  # serve o build
